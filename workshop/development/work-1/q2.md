# 一つの「役割」を切り出してみましょう

複数ある「役割」のうち、Todoクラスのレコードを管理する`TodoRepository`というクラスを作りましょう。

## 手順

1. record Todoを「リファクタリング」→「内部クラスを移動」して別ファイルにする
2. TodoRepository.javaファイルを作って、以下のように実装する
    ```java
    package com.example.study;
    
    import java.util.ArrayList;
    import java.util.List;
    import java.util.concurrent.atomic.AtomicInteger;
    
    public class TodoRepository {
    
        private final List<Todo> todos = new ArrayList<>() {
            {
                add(new Todo(1, "犬の散歩"));
                add(new Todo(2, "夕飯の買い物"));
            }
        };
    
        private final AtomicInteger nextId = new AtomicInteger(3);
    
        public List<Todo> findAll() {
            return todos;
        }
    
        public Todo add(String title) {
            Todo todo = new Todo(nextId.getAndIncrement(), title);
            todos.add(todo);
            return todo;
        }
    }
    ```
3. MainクラスでTodoRepositoryを使うように変更する
